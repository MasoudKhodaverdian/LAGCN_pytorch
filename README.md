# LAGCN_pytorch
implementation of LAGCN in pytorch

the original GitHub repository is [LAGCN](https://github.com/storyandwine/LAGCN/).

the original paper name is  "Predicting Drug-Disease Associations through Layer Attention Graph Convolutional Networks"

[paper link](https://doi.org/10.1093/bib/bbaa243)

### Usage
```shell
git clone https://github.com/MasoudKhodaverdian/LAGCN_pytorch.git
cd LAGCN_pytorch/code
python main.py
```
